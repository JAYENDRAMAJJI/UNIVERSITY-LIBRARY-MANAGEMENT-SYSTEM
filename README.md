# University Library Management System

A comprehensive, modern web application designed for university libraries to streamline book search, circulation, digital resources, member management, and administrative workflows.

---

## 🌟 Key Features

### 📖 User & Student Features
- **Book Search & Cataloging**: Search books by title, author, ISBN, department, and availability status.
- **Digital Library & Open Access**: Browse e-books, journals, past question papers, and institutional repositories.
- **Member Dashboards**: View borrowed books, return due dates, reservation queue, and fine details (Student & Faculty views).
- **Barcode & QR Scanner**: Quick search and book identification using interactive barcode and QR scanning options.
- **Notices & New Arrivals**: Real-time announcements, library rules, and latest acquired books.

### ⚙️ Administration & Circulation
- **Circulation Desk**: Process book issuing, returns, and renewals with automated due date and fine calculations.
- **Inventory & Book Management**: Add, update, categorized catalog, copy tracking, and ISBN management.
- **Member Management**: Track active library memberships, card numbers, user roles (Student, Faculty, Librarian, Admin).
- **Fine & Fee Tracking**: Manage overdue fines, payment statuses, and fee receipts.
- **Procurement & Master Data**: Manage publisher requests, vendors, department tags, and system configurations.
- **Analytics & Reports**: Visual reports for circulation statistics, top borrowed books, and library traffic.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.x or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/JAYENDRAMAJJI/UNIVERSITY-LIBRARY-MANAGEMENT-SYSTEM.git
   cd UNIVERSITY-LIBRARY-MANAGEMENT-SYSTEM
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://127.0.0.1:5173` (or the port specified in terminal output).

4. **Build for production:**
   ```bash
   npm run build
   ```
